# Growing Landing — мой учебный проект

**Growing Landing** — сайт-портфолио, который ты будешь постепенно развивать на занятиях по HTML, CSS и JavaScript. К концу курса у тебя получится собственный адаптивный сайт с интерактивными элементами, который можно будет опубликовать в интернете.

## Как запустить проект

1. Открой папку проекта в редакторе кода (например, VS Code).
2. Открой файл `index.html` в браузере. Для удобства можешь использовать расширение Live Server.
3. Изучи структуру страницы и стили в `css/styles.css`.
4. На каждом занятии выполняй задания и проверяй результат в браузере.

> Некоторые кнопки и поля пока неактивны. Ты подключишь их с помощью JavaScript на соответствующих занятиях.

## Структура проекта

```text
Growing_Landing/
├── index.html          # Главная страница
├── css/
│   └── styles.css      # Стили сайта и адаптивность
├── js/
│   └── script.js       # Твой JavaScript-код
└── README.md           # Описание проекта и задания
```

На лекции №6 ты самостоятельно добавишь страницу `about.html`.

## Что ты уже изучил на лекциях №1–5

- HTML: структура страницы, текст, изображения, ссылки, формы и семантические теги.
- CSS: цвета, шрифты, отступы, размеры, оформление элементов.
- Flexbox и Grid: расположение блоков и карточек.
- Адаптивность: отображение сайта на телефоне, планшете и компьютере.

## Как выполнять лабораторные работы

1. **Сначала изучи тему занятия.** Разберись, какие новые возможности JavaScript понадобятся.
2. **Измени HTML и CSS там, где это требуется.** Не ограничивайся только файлом `script.js`.
3. **Самостоятельно напиши JavaScript.** Используй примеры из лекции как ориентир и проверяй результат.
4. **Проверь сайт.** Убедись, что новая функция работает и предыдущие возможности не сломались.

## Что должно получиться к концу курса

Твой Growing Landing должен включать:
